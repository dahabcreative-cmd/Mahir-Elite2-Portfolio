MAHIR ELITE2 PORTFOLIO
=======================

Files:
- index.html  -> main portfolio
- style.css   -> design and responsive layout
- script.js   -> smooth navigation
- assets/     -> your supplied portfolio photos

Open index.html in Chrome/Edge to preview.

To add your real posters:
1. Put poster images inside assets/
2. Replace the image filenames in index.html inside the "Selected Work" section.
3. Keep filenames simple, e.g. poster-01.jpg.
